Program Python untuk mencatat pengeluaran harian anak kos, lalu menghitung total, rata-rata per hari,
pengeluaran per kategori, dan sisa uang saku.

Struktur: `main.py` (menu) dan package `kos/` (fileio.py, processing.py, validasi.py, testing.py).

Jalankan:
    python main.py               # program utama
    python -m kos.processing     # uji lokal
    python -m kos.testing        # unit test (8 tes)
